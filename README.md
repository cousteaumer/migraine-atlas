# Атлас мигрени

Схема приступа мигрени и вики простым языком: что происходит в голове на каждом шаге — от предвестников до профилактики — и откуда это известно.

**Открыть:** https://cousteaumer.github.io/migraine-atlas/

- **Схема приступа** — 14 шагов на анатомическом рисунке: что происходит и как это ощущается.
- **Вики** — 32 статьи: фазы и симптомы, анатомия, механизмы, триггеры и лечение.
- У каждого шага и каждой статьи — ссылки на исследования в PubMed.

Это объяснение механизмов, а не медицинская рекомендация. Лечение подбирает врач.

Тексты подготовлены с помощью Claude (Anthropic) по научным публикациям; где данных нет или это гипотеза, так и написано.

## Что в репозитории

- `index.html` — вся страница одним файлом. Работает без сервера; из сети подгружает только шрифты Google Fonts.
- `src/` — исходники:
  - `template.html` — разметка, стили, шаги схемы и их источники;
  - `plate.svg.part` — рисунок со всеми наложенными слоями;
  - `wiki_*.json` — статьи вики;
  - `patch_wiki.py` — общие правки статей;
  - `build.py` — сборка.

Пересобрать страницу после правок: `python3 src/build.py`.
